## Featured Projects

### [MASS: Media Aggregation & Sorting System](https://github.com/mudabbir-ahmad/Abstracted-MASS-PublicVer)
*Final Year Project, Sep 2025 - Apr 2026*

A cross-platform React Native app that merges device storage, Google Photos and a home NAS into one timeline view, backed by a RESTful Express.js backend.

* Designed a metadata-driven sorting system for consistent browsing across video, audio and image sources.
* Built the Express.js backend for concurrent requests, cutting average response time by roughly 15%.
* Added API response caching that reduced retrieval latency by around 30%.
* Set up a CI/CD pipeline for automated testing and deployment, cutting manual testing and integration time by about 20%.
* **Tech Stack:** `React Native` `Expo` `Node.js` `Express.js` `REST API`
